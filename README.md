<h2 align="center">🔄 &nbsp;How I Approach a Production Issue</h2>

```mermaid
flowchart LR
    A["🚨 Incident / Ticket"] --> B["📜 Logs & Traces<br/>Elasticsearch · HyperDX"]
    B --> C["🔁 Reproduce Reliably"]
    C --> D["🔎 Isolate Root Cause"]
    D --> E{"Data or Code?"}
    E -- Data --> F["🗄️ SQL · Reconcile · Patch"]
    E -- Code --> G["🧩 Fix · Test · Review"]
    F --> H["🚀 Ship with Monitoring"]
    G --> H
    H --> I["📝 Document & Automate"]
    I --> J["✅ Prevent the Repeat"]
```
